## Visual Assets

All SVG illustrations in this project are original creations made specifically for this educational website. They are simple silhouette-style illustrations created inline in the React components.

### Asset Style
- Consistent minimal line-art style
- Single-color (white/currentColor) with transparency
- Designed for dark ocean backgrounds
- No external image dependencies
